# Review Manager 일반 개발

## 적용 범위

UI·Next.js·Supabase 스키마에만 해당하지 않는 기능 추가, 버그 수정, 리팩터링 작업에 적용합니다. UI, Next.js, DB 스키마 작업은 이 스킬과 함께 해당 전문 스킬도 적용합니다.

## 작업 절차

1. `AGENTS.md`의 프로젝트 개요·주요 디렉터리·DB 공통 맥락에서 관련 화면, 디렉터리, 데이터 책임을 확인합니다.
2. `src/components`, `src/lib`, `src/types`, `supabase`에서 같은 책임의 기존 코드와 공통 로직을 `rg`로 찾습니다.
3. 기존 코드의 확장으로 해결할 수 있으면 새 파일·함수·추상화를 만들지 않습니다.
4. 새 분리가 꼭 필요하면 기존 코드를 재사용하기 어려운 이유와 분리로 얻는 유지보수 이점을 작업 설명에 남깁니다.
5. 요청하지 않은 기능, 설정 가능성, 예외 처리, 인접 코드 정리를 추가하지 않습니다.
6. 새 코드의 주석은 비개발자도 이해할 수 있는 쉬운 한국어로 작성합니다.
7. 프로젝트 구조·동작·책임이 바뀌었으면 `AGENTS.md`의 관련 개요를 갱신합니다.

## 검증

- 변경된 로직에 대응하는 기존 테스트를 먼저 확인하고 필요한 테스트를 추가하거나 수정합니다.
- JavaScript·TypeScript 변경 후 `npm run lint`와 `npm test`를 실행합니다.
- 라우팅, 설정, 의존성, 빌드 결과에 영향을 주는 변경이면 `npm run build`도 실행합니다.
- 검증 실패 원인이 변경과 무관한 기존 문제인지 확인하고 최종 응답에 구분해 적습니다.
